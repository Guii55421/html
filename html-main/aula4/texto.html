O que é estruturação semântica?

Muita gente aprende HTML decorando tags: “quero negrito, uso ; quero itálico, uso “. Funciona visualmente, mas ignora um detalhe importante: HTML não é uma ferramenta de formatação visual, é uma linguagem de estruturação semântica de conteúdo. O CSS cuida da aparência; o HTML cuida do significado.
